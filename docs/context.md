- 结构定义一组允许的计算实现，参数确定其中的具体函数；表达可能性不等于训练可达性或任务可靠性。

- 区分三类使用方式：结构参数都冻结；结构冻结、参数可训练；自行组合基础网络并训练。
- 核心缺口是可组合的功能抽象与推导规则。构造语法、形状匹配或模块名称不足以提供任务语义。
- 参数变化幅度不能普遍代表能力变化；需要区分接口含义、已有行为质量与新能力扩展。
- 信息访问、状态、参数共享等结构性质是候选起点；语义接口、能力部件与约束训练仍是待检验方案。
