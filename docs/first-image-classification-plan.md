## 实验目标

用少量基础结构写出一个图像分类程序，检验能否明确说明每个构造的计算含义，以及组合后哪些性质可以推导。

本方案承接 [网络编程语言的概念与设计设想](neural-programming-concept.md)。图像分类是第一个具体问题，重点是探索稳定、可复用的功能抽象及其组合方式。分类准确率是证据之一，不能单独证明网络编程的抽象已经成立。

首轮需要区分两类结果：由程序构造直接确定的结构性质，以及只有经过训练和测试才能确认的能力表现。

## 任务与数据范围

第一轮使用程序合成图像，不下载数据集。任务是区分铺满画面的横向条纹和纵向条纹，不包含旋转、交叉条纹、遮挡或真实物体。

### 图像、标签与生成公式

单张图像为 `float32[1,32,32]`，像素范围为 `[0,1]`。采用通道、行、列顺序；行坐标 `r` 向下增加，列坐标 `c` 向右增加，均从 0 开始。

- 标签 `0 = horizontal`：沿列方向不变，沿行方向交替，即肉眼看到的横向条纹。
- 标签 `1 = vertical`：沿行方向不变，沿列方向交替，即肉眼看到的纵向条纹。

令横向样本的 `t=r`，纵向样本的 `t=c`，定义：

\[
q(t;w,p)=\left\lfloor\frac{t+p}{w}\right\rfloor\bmod 2,
\qquad I_0[r,c]=b+a\,q(t;w,p)
\]

\[
I[r,c]=I_0[r,c]+\epsilon[r,c],
\qquad \epsilon[r,c]\sim\operatorname{Uniform}(-\eta,\eta)
\]

| 因素 | 首轮取值 | 含义 |
|---|---|---|
| 条纹宽度 `w` | `{2,4,8}`，按下表组合配额分配 | 单条亮带或暗带的像素宽度，完整周期为 `2w` |
| 相位 `p` | 整数 `{0,…,2w-1}`，条件均匀采样 | 控制条纹位置与明暗起始顺序，不移动画布、不填充边框 |
| 暗部亮度 `b` | 连续均匀分布 `[0.10,0.30]` | 两个类别使用相同分布 |
| 对比度 `a` | 连续均匀分布 `[0.30,0.50]` | 亮部亮度为 `b+a` |
| 噪声幅度 `η` | `{0,0.03,0.08}` | 各像素独立的有界加性噪声；不是标准差 |

以上范围使像素自然落在 `[0.02,0.88]`，无需裁剪，也不进行逐图归一化。亮暗带的数值区间不重叠，且每张图都有多个条纹边界，因此避免了纯色、零对比度或条纹宽于画面造成的方向歧义。标签由生成方向确定，不由滤波结果反推。仅存在噪声或不存在唯一方向的图像不进入二分类数据集。

### 数据划分与防止泄漏

将 `(w=8, η=0.08)` 整个组合留作组合泛化测试。训练中仍出现宽度 8 和噪声幅度 0.08，但二者不同时出现；这检验未见组合，不是未见单个因素取值。

| 划分 | 样本数 | 宽度与噪声组合 | 配额与用途 | 生成种子 |
|---|---:|---|---|---:|
| 训练 | 6,000 | 其余 8 种组合 | 每个组合、每个类别 375 张 | 4101 |
| 验证 | 1,200 | 同上 | 每个组合、每个类别 75 张；用于选择配置 | 4102 |
| 同分布最终测试 | 1,200 | 同上 | 每个组合、每个类别 75 张；配置确定后评估 | 4103 |
| 未见组合最终测试 | 1,200 | 仅保留组合 | 每个类别 600 张；配置确定后评估 | 4104 |

表中配额优先于对 `w` 和 `η` 分别独立采样；在每个配额内独立采样 `p、b、a` 和噪声。A、B、C 使用完全相同的样本清单。首轮共 9,600 张分类样本，另有独立接口诊断样本。

生成时保存样本 ID、划分、标签、全部生成参数、噪声随机状态或子种子，以及生成器版本、随机数算法和数值精度。上述种子属于数据生成，不代替后续训练的随机种子；种子本身也不足以保证跨实现逐位复现。

先分配基础样本，再生成噪声或诊断变体。同一基础样本的转置、亮度变化、明暗反转及不同噪声版本必须留在同一划分；基础样本族按 `(w,p,b,a)` 识别，不用类别或噪声区分。按确定的样本生成顺序检查跨划分的样本族冲突与最终像素重复，冲突时重采样并记录。验证集与最终测试集不能参与参数更新，最终测试结果不能用于选择训练配置。

## 基础构造与组合规则

首轮定义五种计算操作；下列定义足以描述本实验，不要求每个程序都使用全部操作。各操作都是无持久状态的纯计算，不跨样本或跨批次读写状态。

| 基础构造 | 精确计算含义 | 不由构造名称直接保证的功能 |
|---|---|---|
| 局部线性变换 | 步长 1、无填充、不翻转核的局部加权和，无偏置 | 不自动等于边缘或纹理提取 |
| 逐点非线性 | 本实验使用 `abs(z)=|z|`，保留形状 | 不自动等于概念激活 |
| 空间聚合 | 本实验对全部空间位置求均值，仅归约行、列轴 | 不自动保证位置不变性 |
| 重排 | 明确轴顺序的置换，或明确元素顺序的展平 | 不宣称产生新信息 |
| 全连接变换 | 对每个样本的特征向量执行 `z=Wf+b` | 不自动具有分类器的任务含义 |

### 五种构造的计算定义

统一批量布局为 `X[N,C,H,W]`，`N≥1`；输入、中间张量与参数均采用 `float32`，各样本独立计算。局部变换的参数为 `K[C_out,C_in,k_h,k_w]`：

\[
Y[n,o,r,c]=\sum_{i=0}^{C_{in}-1}\sum_{u=0}^{k_h-1}\sum_{v=0}^{k_w-1}
K[o,i,u,v]X[n,i,r+u,c+v]
\]

输出为 `[N,C_out,H-k_h+1,W-k_w+1]`，要求输入空间尺寸不小于核尺寸；同一核在所有空间位置与样本间共享。这里定义的是不翻转核的互相关计算，不隐含补零、循环边界、偏置或额外激活。

逐点非线性定义为 `A[n,c,r,s]=|Y[n,c,r,s]|`。它消除差分正负号，避免明暗交替在均值中相互抵消；不保留亮到暗或暗到亮的极性。若进入训练，约定绝对值在零点的反向传播导数取 0，正数取 1，负数取 -1。

空间均值定义为：

\[
f[n,c]=\frac{1}{H'W'}\sum_{r=0}^{H'-1}\sum_{s=0}^{W'-1}A[n,c,r,s]
\]

输出 `[N,C]`，不归约批量轴或通道轴。均值保留每个通道的平均响应幅度，丢弃响应发生的位置；有限画面内的条纹边界数可能随相位变化，因此不宣称对任意平移严格不变。

重排包含两种显式操作：`permute(order)` 必须给出全部轴且每轴恰好一次，批量轴仍保持首位；`flatten_features` 按通道、行、列顺序将 `[N,C,H,W]` 转为 `[N,C×H×W]`，列索引变化最快。不允许隐式交换轴或混合不同样本；二者无参数、无信息丢失，本次主程序不需要重排。

全连接变换输入 `f[N,d]`，参数为 `W[m,d]`、偏置 `b[m]`：

\[
z[n,j]=\sum_{i=0}^{d-1}W[j,i]f[n,i]+b[j]
\]

输出 `[N,m]`，不隐含非线性或概率归一化；本实验 `d=m=2`。偏置仅沿批量轴广播。

### 组合规则

- `chain(F,G)(x)=G(F(x))`：按书写顺序执行，逐段核对形状和语义约定；不自动展平、转置或插入投影。
- `parallel(F,G)(x)=(F(x),G(x))`：两条分支读取同一输入，返回有序二元组，第一项对应 `F`；不隐式拼接。
- `concat_channels`：接收有序的四维张量元组，要求批量大小、空间尺寸与数值类型一致，按元组顺序沿通道轴拼接。不得广播、求和或自动调整尺寸。

本轮合并仅支持上述通道拼接；残差求和和其他合并方式暂不纳入首轮规则。组合时形状兼容只是必要条件，模块语义及其适用条件也必须兼容。维度、数值类型或已声明语义不兼容时，应报错或标记契约失败，不能静默改写接口。

组合规则先支持串联、并联与合并。循环、持久状态、注意力和更复杂结构留到后续讨论。

局部核只能读取其覆盖的邻域；非线性只读取单个元素；空间均值读取同一通道的全部位置；全连接读取单个样本的全部特征。以上访问范围由构造决定，不直接保证识别能力。

## 模块接口与语义约定

### 固定方向响应的参考定义

两个分支均采用 `2×2` 核，输入单通道、输出单通道：

\[
K_h=\begin{bmatrix}-1&0\\1&0\end{bmatrix},
\qquad K_v=\begin{bmatrix}-1&1\\0&0\end{bmatrix}
\]

`K_h` 计算 `I[r+1,c]-I[r,c]`，即沿行方向的变化，用于响应横向条纹；`K_v` 计算 `I[r,c+1]-I[r,c]`，即沿列方向的变化，用于响应纵向条纹。下标指条纹朝向，不指差分方向。两者只计算 `r,c∈{0,…,30}` 的共同有效区域，不访问画面外部。

| 边界 | 形状与顺序 | 语义与限制 |
|---|---|---|
| 输入 `images` | `float32[N,1,32,32]` | 有限数值且在 `[0,1]`；生成范围决定适用性，形状校验不负责识别域外图像 |
| 分支输出 | 两个 `[N,1,31,31]` 组成的有序元组 | 先行差分、后列差分；固定参考核下数值在 `[-1,1]` |
| 拼接响应 `responses` | `[N,2,31,31]` | 通道 0 为横向条纹响应，通道 1 为纵向条纹响应，仍带正负号 |
| 绝对响应 `magnitudes` | `[N,2,31,31]` | 对应差分的绝对值；固定参考核下在 `[0,1]` |
| 特征 `features` | `[N,2]`，顺序 `[e_h,e_v]` | 平均绝对差分幅度；不是类别概率，也不单独表示条纹存在概率 |
| 判断输出 `scores` | `[N,2]`，顺序 `[s_h,s_v]` | 类别分数，数值越大越倾向对应类别；不默认具有概率校准含义 |
| 预测 `labels` | 整数 `[N]` | `0=horizontal`，`1=vertical`，不得在训练后交换类别编号 |

判断接口统一采用：`s_h≥s_v` 时输出 0，否则输出 1；同时记录 `tie = (|s_h-s_v|≤10^-6)`。近似相等标记只用于诊断，不改变上述大小比较规则；准确率统计包含所有样本，不丢弃平局。NaN、无穷值、形状错误属于无效输出，不能当作平局处理。若需要展示概率，可以另行归一化，但不改变分数和标签接口。

固定参考核下，无噪声横向条纹满足 `e_h>0、e_v=0`，纵向反之。具体而言，若有效差分区间内有 `B` 个条纹边界，则目标方向响应为 `aB/31`。因此，幅度同时受对比度和边界数量影响，不能称为独立于宽度、对比度的“方向置信度”。噪声会使两个通道都非零；正确类别通道是否仍然占优应由实验检查，不从无噪声性质直接外推。

### 语义契约与诊断样本

固定参考模块应满足下列可由公式推导的关系；未来实现仍需用数值检查核对它是否符合定义。数值等式以绝对误差 `10^-6` 检查。

- **方向选择性**：构造无噪声条纹，遍历 `w∈{2,4,8}`、全部合法相位、`b∈{0.10,0.30}`、`a∈{0.30,0.50}`、两个类别，共 224 张探针图。非目标通道应接近 0，目标通道应满足 `aB/31`，且比非目标通道至少高 `10^-6`。
- **常量响应**：单独使用亮度 `0、0.5、1` 的纯色图，两个通道都应为 0。这些图没有二分类真值，仅用于接口诊断，不纳入准确率。
- **转置关系**：对每张探针图做行列转置，`[e_h,e_v]` 应交换，生成方向标签随之交换。
- **亮度与极性关系**：对探针图加常数 `0.05`，特征应不变；对图像做 `1-I`，特征也应不变。仅在变换后像素仍在 `[0,1]` 且不裁剪时声明这些关系。
- **幅度关系**：对探针图做 `0.5I`，两个特征都应乘以 `0.5`；这检验响应幅度的含义，不代表分类分数必须具有同样关系。

诊断探针及其变体作为独立、公开的接口检查集保存，与四个分类划分分开并去重，不充当隐藏的最终测试数据。它们可用于定位实现错误；若后续用作训练目标，必须另记为实验条件，不能再称为独立验证。

在 C 中，核可训练后只能先称为“通道 0/1 的绝对局部响应”；是否仍能称为固定参考意义下的“方向响应”，需要重新检查。分别报告方向选择性通过比例、各关系的最大绝对误差，以及相对固定参考特征的偏差；不能只因分类准确率提高就宣布语义保持，也不能事后交换通道来掩盖原接口变化。若只保留方向偏好而失去原幅度关系，应明确记为较弱的语义保持。完整实验的通过阈值与取舍仍属于后续验收设计。

C 保留两个 `2×2` 核的形状与通道顺序，各核的全部四个系数均可训练，参考定义中的零不作为固定掩码。因此训练后不自动保持差分含义、亮度不变性或参考核的数值范围；非负性仍由绝对值与均值保证。C 的具体初始化留到对照实验配置中确定。

## 参数使用方式与拟议程序

参数的使用方式属于程序定义的一部分，分成两个独立维度：

- **固定或可训练**：`fixed` 不允许更新参数，`learn` 允许训练更新。无参数操作不需要声明此属性。
- **共享或独立**：重复引用同一实例 ID 使用同一份参数；新建实例即使初值相同，也拥有独立参数。共享实例可以固定，也可以可训练；同一共享参数不能同时声明为固定和可训练。

局部核在空间位置间共享是局部变换自身的定义；两个方向分支之间不共享参数，判断模块与特征模块之间也不共享。A、B、C 各自持有独立参数副本，避免 C 的更新影响 A 或 B。所有模块均无运行状态；共享参数不引入跨样本记忆。实验记录需列出实例 ID、参数形状、初值来源、可训练标志及所有引用位置。

下面是拟议语法，用于表达设计意图，尚非可运行接口：

```python
responses = chain(
    parallel(
        fixed(local_filter(K_h)),
        fixed(local_filter(K_v)),
    ),
    concat_channels(),
)

features = chain(
    responses,
    pointwise_abs(),
    spatial_mean(axes=(2, 3)),
)

classifier = chain(
    features,
    learn(affine(outputs=2)),
)
```

此示意对应 B 的计算结构，`K_h、K_v` 使用前述参考定义，聚合后形状为 `[N,2]`，判断输出为 `[N,2]`。拟议函数名称尚未绑定到任何实现框架。B 的判断模块初始化、训练方法，以及 A 的完整判断模块和 C 的训练配置仍待后续定义。

此程序旨在同时表达计算结构、已知部分与待学习部分。

## 三个对照版本

在同一任务与一致的数据划分上比较三个版本：

| 版本 | 构造方式 | 研究问题 |
|---|---|---|
| A | 固定特征计算与固定判断规则 | 能否完整解释并验证一个网络程序？ |
| B | 固定特征计算，只训练判断模块 | 能否保持中间含义，同时学习新的组合？ |
| C | 特征计算与判断模块联合训练 | 性能改变时，中间接口的含义是否仍然成立？ |

A 提供可理解的参照，B 检验模块组合，C 研究学习自由度与语义稳定性的冲突。三个版本不要求内部表示完全相同。

A 的适用范围和判定规则需要明确；固定参数不会自动带来正确性保证。B 与 C 的训练设置、冻结范围及参数共享关系需要记录，避免把配置差异误解为抽象本身的效果。

## 结构说明与能力验证

每个程序分别维护两份说明：

**结构说明**记录输入输出维度、局部连接、参数共享、聚合范围等可从定义检查的性质。

**能力证据**记录分类表现，以及位置、亮度、宽度、噪声和未见因素组合下的表现。这些结论来自实验，不作为结构天然保证的性质。

测试需要同时关注最终结果与中间接口。例如，一个通道若被称为“横向响应”，应检查训练前后它是否仍按约定响应横向结构。最终准确率提高，不代表中间语义得到保留。

实施时沿用前述数据划分、生成配置和接口诊断，另行记录训练随机种子与训练配置。测试通过仅支撑所覆盖的条件，不宣称对任意图像成立。

## 交付内容与判断标准

首轮交付控制在四项：

1. 基础构造与组合规则规范。
2. 使用相同任务接口的三个网络程序。
3. 可控图像数据生成方式及诊断测试。
4. 结果分析，区分可由构造推导的性质与只能通过实验确认的行为。

成功标志是找到至少一种有明确适用范围、能够复用的功能抽象，并用它解释或预测组合行为。若只换了一种写法搭出分类网络，即使准确率很高，也尚未验证本设想的核心价值。

如果实验发现模块含义在训练中不稳定，或已有说明不足以推断组合结果，也应如实记录为对抽象设计的反馈，而不是仅通过扩大网络追求更高分数。
