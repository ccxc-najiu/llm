# 残差连接对参数训练轨迹的影响实验方案

日期：2026-10-15。状态：待实施。用户将在有 GPU 的机器上实现；本轮仅保存方案。

## 实验目标与对照条件

观察完全相同的初始参数，在加入或去掉残差连接后，如何沿不同轨迹变化，直至 loss 稳定。主要研究对象是每个参数的数值、相对初值的变化和逐步更新量。loss 只用于判断训练状态与停止时刻，不分析或可视化预测输出。

用户明确要求相同初始权重。两组权重和偏置逐项完全一致，数据及顺序、优化器和所有训练超参数一致，唯一主动改变的条件是残差连接开关。相同初始函数不作为实验要求，不为对齐输出而修改初始权重。

以下任务、规模和数值是可直接采用的首轮配置，尚未经过试运行，不预设哪组更快收敛。

## 简单任务

使用一维函数回归，直接生成 256 个无噪声样本，无需下载数据：

\[
x_i=-1+\frac{2i+1}{256},\quad i=0,\ldots,255
\]

\[
y_i=0.5\sin(\pi x_i)+0.2
\]

按输入从小到大保存数据。每一步使用全部 256 个样本计算均方误差，消除小批次采样的影响：

\[
L(\theta)=\frac1{256}\sum_i\big(f_\theta(x_i)-y_i\big)^2
\]

训练目标只提供 loss。首轮不设置输出拟合图、分类准确率或泛化评测。

## 网络结构

两组都包含 4 个参数独立的模块。模块输入和输出为标量，内部有 4 个隐藏单元：

\[
F_l(h)=W_{l,2}\tanh(W_{l,1}h+b_{l,1})+b_{l,2}
\]

其中 \(W_{l,1}\in\mathbb R^{4\times1}\)、\(b_{l,1}\in\mathbb R^4\)、\(W_{l,2}\in\mathbb R^{1\times4}\)、\(b_{l,2}\in\mathbb R\)。每个模块有 13 个参数，整个网络共 52 个参数。

普通网络：

\[
h_0=x,\qquad h_{l+1}=F_l(h_l),\qquad f(x)=h_4
\]

残差网络：

\[
h_0=x,\qquad h_{l+1}=h_l+F_l(h_l),\qquad f(x)=h_4
\]

模块编号为 0 到 3。两组均不加入 BN、Dropout、额外输出头或相加后的激活函数。残差路径是无参数的恒等连接，参数数量、名称和形状完全对应。这是用于观察残差核心的小型 MLP，不复现完整的图像 ResNet。

## 固定初始化和训练设置

| 项目 | 首轮配置 |
|---|---|
| 初始化种子 | 20261015 |
| 权重初始化 | 每个线性层采用 Xavier uniform，gain 为 1 |
| 偏置初始化 | 全部为 0 |
| 参数配对 | 只生成一次初始参数，深拷贝给两组模型 |
| 训练数据 | 同一份保存的数据，固定升序 |
| 批大小 | 256，全批量，每次参数更新为一步 |
| 优化器 | 普通 SGD，无动量、无权重衰减 |
| 学习率 | 固定为 0.01 |
| 精度与设备 | 同一张 GPU，float32；关闭混合精度和 TF32 |
| 其他训练操作 | 不使用学习率调度、梯度裁剪或数据增强 |
| 单次步数上限 | 20000 步 |

两组分别创建优化器，参数张量不能共享存储，否则训练其中一组会改变另一组。初始化后逐项检查名称、形状和数值完全相等；仅设置相同随机种子不能替代这项检查。

固定所有实际使用的随机数生成器，启用确定性算法并完成当前 CUDA 版本要求的配置。保存 Python、框架、CUDA、cuDNN、GPU 型号与确定性设置。复现目标是同一软硬件环境下重复训练；跨框架版本、平台或设备不保证逐位相同。[PyTorch 可复现性说明](https://docs.pytorch.org/docs/stable/notes/randomness.html)

首轮使用同一固定学习率比较。若出现数值异常或预算内没有稳定，如实保存该次结果；后续可建立新的配对实验，分别使用 0.001、0.01、0.1，每一对使用相同设置，并保留全部结果。该扩展不替换首轮记录。

## 记录每一步的参数

将 52 个参数按固定名称及张量索引展开为 \(\theta_t\)。保存真实数值和索引映射，不能只保存参数范数、分布直方图或最终权重。

时间编号统一为：\(\theta_0\) 是任何更新之前的初值；\(\theta_t\) 是完成第 \(t\) 次更新后的参数；\(L_t=L(\theta_t)\)。最后一次更新后的参数和 loss 也必须保存。

每一步保存：

- 步数 \(t\)。
- 全部参数 \(\theta_t\)，包括权重和偏置。
- 与该组参数对应的全批量 loss \(L_t\)。

由完整记录直接计算：

\[
d_{t,p}=\theta_{t,p}-\theta_{0,p}
\]

\[
u_{t,p}=\theta_{t,p}-\theta_{t-1,p}\quad(t\ge1)
\]

分别表示参数 \(p\) 相对初值的变化和该步更新量。也可计算每个模块及全网络的累计路径长度 \(\sum_{k=1}^{t}\|\theta_k-\theta_{k-1}\|_2\) 与离初值的距离 \(\|\theta_t-\theta_0\|_2\)。这些数值只描述给定参数坐标下的变化。

首轮无需额外记录预测输出、激活值或完整梯度。普通 SGD 下，更新量已经对应负梯度乘学习率；若后续改用动量或 Adam，就不能沿用这一对应关系。

## loss 稳定与停止规则

两组分别训练到满足停止规则或达到共同上限，不预设它们一定能在预算内收敛。

至少更新 2000 步。之后每 100 步检查最近连续 500 个 \(L_t\)。记窗口内均值为 \(\bar L\)，若

\[
\max L_t-\min L_t\le10^{-6}\max(1,\bar L)
\]

并且连续 3 次检查都满足，则按本实验的数值标准判为 loss 稳定，保存末态并停止该组。这是有限窗口的操作性判断，不是数学上的收敛证明。

停止时区分：

| 状态 | 判定 |
|---|---|
| 低 loss 稳定 | 满足稳定规则，且最后窗口的平均 MSE 不超过 \(10^{-4}\) |
| 高 loss 平台 | 满足稳定规则，但平均 MSE 高于 \(10^{-4}\) |
| 预算内未稳定 | 达到 20000 步，仍未满足稳定规则 |
| 数值异常 | loss 或参数出现 NaN、Inf，立即保留最后有效状态和异常位置 |

高 loss 平台单独标记，避免把参数几乎不动的训练停滞误读为成功拟合。loss 稳定也不保证所有参数已经停止变化，参数末段轨迹本身仍是观察对象。

两组实际训练长度不同是允许的。相同步数的直接比较只覆盖双方均有真实记录的区间；较长轨迹继续显示，较早停止的一组留空，不用复制末态伪造后续训练。

## 参数可视化

主视图按模块组织，默认选择一个模块查看其全部 13 个参数。每个参数单独一幅小图，横轴为训练步数，普通网络和残差网络用两种固定线型及颜色表示。同一参数的两组曲线共享坐标尺度，避免把独立缩放造成的形状相似误当作相同变化。

提供三个可切换的纵轴：

1. 参数原值 \(\theta_{t,p}\)，查看最终值、变号与变化过程。
2. 相对初值变化 \(d_{t,p}\)，查看各参数离开共同起点的方向和幅度。
3. 逐步更新量 \(u_{t,p}\)，查看哪些参数较早变化、长期不动或出现往返变化。

补充一幅“参数 × 步数”热力图展示全部 52 个参数的变化，以及模块级距离和累计路径长度曲线。热力图的参数顺序与色阶在两组间保持一致；原值、变化量和更新量使用各自明确标注的尺度。

loss 只占一个辅助视图，用来标注停止时刻、稳定状态，以及首次达到 MSE 为 \(10^{-2}\)、\(10^{-3}\)、\(10^{-4}\) 的位置。未达到的阈值显示“未达到”。主要比较使用真实步数；在两组都达到某阈值时，可补充查看对应参数状态。

所有参数的完整逐步记录必须保留。显示端为流畅而抽样时，应注明显示抽样，并允许选择单个参数查看完整轨迹。不以 PCA 或少数主成分替代逐参数视图。

## 观察问题和解释范围

优先观察：哪些参数先发生明显变化；前后模块的变化是否不同；哪些参数出现较长静止段；两组最终离共同初值有多远；到达相同步数或相同 loss 阈值时，走过的参数路径有何差异。

不把“参数变化更小”直接等同于训练更好，也不把某个参数的变化直接解释为获得某种能力。相同名称只保证坐标对应，训练后隐藏单元的作用可能分化。

本实验回答：在指定任务、相同初始权重和固定训练设置下，切换残差连接会怎样改变参数轨迹。加入残差会改变前向计算和 loss 对参数的关系，因此曲线呈现的是这次结构改变在该配置下的整体影响，不能仅凭它们断言单一原因，也不要求两组输出相同。

首轮先完成一个固定种子的配对实验。需要判断现象是否稳定时，再增加预先列出的种子 0、1、2、3、4，每一对仍从完全相同的权重出发；展示每个种子的轨迹及结果，不只挑选差异最大的例子。

## 实施交付与验证

实施时交付训练配置、固定数据和初始参数、带参数索引映射的完整轨迹、loss 与停止状态、从保存结果生成的参数可视化。绘图应读取已有轨迹，不因切换视图重新训练。

最小验证包括：两组初始参数逐项相同；两组参数存储独立；每条记录的步数、参数和 loss 对齐；任意相邻快照能恢复更新量；同环境重复运行能复现轨迹；所有停止原因如实保存。

本方案只使用残差核心 \(x+F(x)\)。残差学习的原始研究可作为背景，但其中的大规模实验结果不是本小型网络的预期结论。[Deep Residual Learning for Image Recognition](https://arxiv.org/abs/1512.03385)
